# sms_inbox

Read-only access to the Android SMS inbox for Flutter apps.

- Check and request the `READ_SMS` permission.
- Read inbox messages **incrementally** by message id, so an app can pick up
  exactly where it left off.
- Filter by received time and by sender (case-insensitive), in the query, not
  in Dart.
- Queries run on a background thread.
- No network access, no storage, no analytics. The plugin reads the inbox
  content provider and hands the rows to Dart; nothing else.

Android only. iOS does not allow apps to read SMS.

## Why another SMS package

The widely used SMS plugins are unmaintained or split across forks. This one
does a single job (reading the inbox) with a small, typed API built on
[Pigeon](https://pub.dev/packages/pigeon), and tests for the Dart side.
Sending SMS and acting as the default SMS app are out of scope.

## Setup

Add the permission to your app's `android/app/src/main/AndroidManifest.xml`:

```xml
<uses-permission android:name="android.permission.READ_SMS" />
```

The plugin does not declare it for you, on purpose: Google Play restricts
`READ_SMS`, and each app has to justify its own use (see
[Google Play policy](#google-play-policy)).

Minimum Android SDK: 24.

## Usage

```dart
import 'package:sms_inbox/sms_inbox.dart';

final inbox = SmsInbox();

// Show your own explanation first, then:
if (!await inbox.requestPermission()) {
  return; // not granted
}

// One page: up to 500 messages after id 0, oldest first.
final messages = await inbox.query(limit: 500);

// Everything from two senders in the last 90 days, page by page.
await for (final page in inbox.pages(
  senders: ['bKash', 'NAGAD'],
  since: DateTime.now().subtract(const Duration(days: 90)),
)) {
  for (final sms in page) {
    print('${sms.id} ${sms.address} ${sms.date}: ${sms.body}');
  }
}
```

### Reading only new messages

Message ids grow as messages arrive. Store the largest id you have processed
and pass it as `afterId` next time:

```dart
final lastSeenId = await loadLastSeenId(); // your storage
await for (final page in inbox.pages(afterId: lastSeenId)) {
  await process(page);
  await saveLastSeenId(page.last.id);
}
```

### Errors

Platform failures throw `SmsInboxException` with a `code`:

| Code | Meaning |
|---|---|
| `permissionDenied` | `READ_SMS` is not granted. |
| `noActivity` | `requestPermission` was called without a foreground activity. |
| `requestInProgress` | A permission prompt from this plugin is already showing. |
| `detached` | The plugin is not attached to an engine. |
| `unknown` | Anything else. |

`query` throws `RangeError` for a `limit` outside `1..SmsInbox.maxLimit`
(5000).

## API

| Member | Description |
|---|---|
| `hasPermission()` | Whether `READ_SMS` is granted. |
| `requestPermission()` | Shows the system prompt if needed; returns whether it is granted. |
| `query({afterId, since, until, senders, limit})` | One page of inbox messages, oldest first. |
| `pages({afterId, since, until, senders, pageSize})` | Stream of pages until the inbox (or window) is exhausted. |

`SmsMessage` fields: `id`, `address`, `body`, `date` (UTC), `dateSent` (UTC,
optional), `subscriptionId` (multi-SIM, optional), `threadId`, `isRead`.

## Google Play policy

`READ_SMS` is a restricted permission. Apps that are not the default SMS
handler need an approved exception through the Permissions Declaration Form.
Permitted uses include SMS-based money management, backup, device automation
and a few others; see Google's
[SMS and Call Log permissions policy](https://support.google.com/googleplay/android-developer/answer/10208820).
Apps distributed outside Google Play are not subject to this review.

## Privacy

The plugin reads messages only when your app calls it, returns them to your
Dart code, and keeps nothing. What happens to the messages after that is up to
your app. If you only need some messages, filter by `senders` so the rest never
cross the platform channel.

## Contributing

Issues and pull requests are welcome. Never paste real SMS content, phone
numbers or transaction ids into issues; use made-up values.

The platform channel is generated by Pigeon from `pigeons/messages.dart`:

```bash
dart run pigeon --input pigeons/messages.dart
dart format lib/src/messages.g.dart
```
